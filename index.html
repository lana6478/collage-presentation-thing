Understanding the software running on a UTC Leeds machine

Every device you use is built from layers of software, each doing a different job — from the operating system that starts the machine, down to the browser you open to reach a lesson resource. This guide walks through each layer in plain terms, with the examples you're most likely to come across on site.

Operating system software

The operating system is the software that runs the software. Think of it as the foundation everything else sits on: it gives you a graphical interface so the computer is intuitive to use, especially if you're new to it, and it controls every individual component in the machine — the screen, the storage, the network card, the keyboard.

Examples Microsoft Windows · Linux · macOS

System software

System software is a type of program designed to run, manage and control computer hardware, while providing a platform for other programs to run on top of. Its job is to sit between the physical hardware and the person using it, making the computer easier to control.

Creative software

Creative software covers the applications used to design, edit and manage artistic or multimedia content. It's usually built by large software companies with an extensive range of settings, so the work can be finely tuned to whatever the user needs. Adobe Creative Cloud is a good example: a package containing several tools bundled together, including photo and video editors and a 3D & VFX editor.

Examples Adobe Photoshop · Premiere Pro · Blender

Utility software

Utility software is used to maintain, optimise and protect a device. This is the software working quietly in the background — keeping the machine secure, keeping files organised, keeping storage tidy.

Examples Windows Defender · WinRAR · CCleaner

Productivity & office suites

Applications built for creating documents, organising data and handling everyday business or school workflows — the tools you'll use for coursework, reports and day-to-day admin.

Examples Microsoft Word · Excel · PowerPoint

Database management systems (DBMS)

A DBMS is used to store, modify, extract and organise large amounts of structured data. Beyond just storage, it also handles data security, backup and recovery, and keeps that data accurate and consistent over time.

Examples MySQL · MongoDB

Web browsers

The interface software used to access, navigate and display information on the internet. Browsers are some of the most-used software in existence, giving access to servers and computers right across the globe.

Examples Google Chrome · Apple Safari · Microsoft Edge

Application software

Application software is a program designed to help users carry out specific personal, educational or business tasks. A word processor is a good example: it's used to write and edit text documents, and is a staple in businesses of every size.
