The general computer
software guide

Eight categories of software every UTC Leeds staff member relies on — what each one does, how it differs from the rest, and where you'll meet it day to day.

01

Operating system software

The operating system is the primary software running on a computer — think of it as the software that runs the other software. It provides the graphical interface that makes a machine intuitive to use, which matters most for people new to computing, and it controls every individual hardware component underneath.

  • Microsoft Windows
  • Linux
  • macOS
02

System software

System software is a category of program designed to run, manage and control computer hardware while giving applications a stable platform to run on. Its job is to sit as a layer between the physical hardware and the user, so the machine is easier to control.

03

Creative software

Creative software covers digital applications built to help individuals and professional teams design, edit and manage artistic or multimedia content. It's usually produced by large software companies and comes with an extensive range of settings, so the work can be fine-tuned to the exact needs of the user.

  • Adobe Creative Cloud
  • Photo & video editors
  • 3D & VFX tools
04

Utility software

Utility software is a set of tools designed to maintain, optimise and protect digital devices — covering everything from security to file compression to disk cleanup.

  • Windows Defender
  • WinRAR
  • CCleaner
05

Productivity & office suites

These are applications tailored for creating documents, organising data and running everyday business workflows — the tools most staff open first thing every morning.

  • Microsoft Word
  • Excel
  • PowerPoint
06

Database management systems (DBMS)

A DBMS is software used to store, modify, extract and organise large amounts of structured data. It also handles related tasks such as securing data, backup and recovery, and maintaining data integrity.

  • MySQL
  • MongoDB
07

Web browsers

A browser is the interface software used to access, navigate and display information on the internet. It's one of the most-used categories of software, since it provides access to servers and computers across the globe.

  • Google Chrome
  • Apple Safari
  • Microsoft Edge
08

Application software

Application software is a computer program designed to help users carry out specific personal, educational or business tasks. A word processor is a good example — it's used for writing and editing text documents, and is a staple of both large and small businesses.
